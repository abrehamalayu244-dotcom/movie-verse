# 🎬 Movie Verse

A dynamic, fully responsive web application built with HTML5, CSS3, and Vanilla JavaScript. The app integrates with **The Movie Database (TMDB) API** to fetch real-time movie details, popular titles, genres, and ratings.

---

## ✨ Features

* **Popular Movies Grid:** Automatically fetches and displays trending/popular titles on launch.
* **Live Search:** Dynamic search bar to find any movie in the TMDB database instantly.
* **Genre Filter:** Filter movies across multiple genres (Action, Comedy, Drama, Sci-Fi, etc.) using official TMDB genre IDs.
* **Rating Filter:** Filter titles by minimum rating scores.
* **Detailed Movie Modal:** Click any card to open an interactive modal displaying plot overviews, runtime, release dates, and complete metadata.
* **Robust Error & Image Handling:** Fallback placeholders for missing poster paths and missing details.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3 (Flexbox/Grid), JavaScript (ES6+)
* **API:** [TMDB API](https://www.themoviedb.org/documentation/api) (Fetch API & Promises)
