# 🎬 CineVerse - Movie Discovery & Watchlist App

A dynamic, single-page web application built with vanilla JavaScript that allows users to explore trending movies, search by keywords, filter by genre/rating/release year, and curate a personalized watchlist using browser local storage.

---

## ✨ Features

- **Dynamic Search:** Real-time text search connected to TMDB's Search API.
- **Advanced Filtering:** Filter movies by **Release Year**, **Rating**, and **Genre** simultaneously.
- **Interactive Watchlist:** 
  - Save movies locally using `localStorage`.
  - Toggle between the primary Movie Feed and your custom Watchlist view with a single click.
  - Controls dynamically lock while in Watchlist mode to preserve navigation state.
- **Pagination / Infinite Scroll:** Load more movie results dynamically without refreshing the page.
- **Responsive Layout:** CSS Grid and Flexbox layout for mobile, tablet, and desktop viewports.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **API Integration:** [The Movie Database (TMDB) API](https://www.themoviedb.org/documentation/api)
* **Storage:** Browser `localStorage` API
